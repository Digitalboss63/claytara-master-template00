# Claytara Digital WordPress Theme

This repository is the authoritative source for the Claytara Digital website theme.

## Repository

`Digitalboss63/claytara-master-template00`

Default branch: `main`

## Working rules

All coding agents and contributors must read `AGENTS.md` before making changes. Claude is directed to the same protocol through `CLAUDE.md`, and GitHub coding agents through `.github/copilot-instructions.md`.

Do not treat exported ZIP files, local WordPress copies, or staging uploads as the source of truth. Changes should be committed back to this repository so every agent works from the same current version.

## Current repair priorities

1. Responsive media sizing, cropping, intrinsic dimensions, and performance.
2. Homepage and site-wide visual consistency across desktop, tablet, and mobile.
3. Navigation and mobile-menu verification.
4. Site Integrations settings, including the authoritative Accessibility/ADA embed path.
5. Light/Dark/Auto appearance verification where applicable.
6. Forms and lead-generation workflow verification.
7. PHP/browser-console cleanup and release QA.
8. Claytara positioning/presentation polish so the site credibly represents the parent product studio behind products such as Find Home First.

## Release discipline

Significant changes must be recorded in `CHANGELOG.md` and verified according to `AGENTS.md` before being called production-ready.
